## 科研项目

**视觉语言模型在自动驾驶问答场景中的优化**，*2024.12 – 2025.03*
- 设计并实现了一个用于自动驾驶多视角信息融合的视觉-语言模型。
- 使用 ViT-B/32 作为图像编码器进行多视角编码，通过交叉注意力机制融合多视角图像嵌入（前、左前、右前、左后、右后），使用 T5-Base 作为文本解码器。
- 在 DriveLM 数据集上，以更小的计算资源（0.94 GB）超越了 DriveLM-Agent 的 ROUGE-L 和 CIDEr 指标。

**teco-RAG：检索增强生成优化**，*2024.11 – 2024.12*
- 构建了 RAG 框架下的高效文档加载与处理系统，优化索引、检索和生成流程。
- 使用 RapidOCR 处理非结构化 PDF，设计块级层次化文档解析流程，结合大模型生成摘要。
- 实现 Query Rewrite 查询优化、文件级路由以及向量嵌入 + BM25 混合检索，结合 bge-reranker 重排序。
- 优化 Prompt 策略，减少幻觉问题，提升生成质量。

**基于可解释性强化学习的游戏代理算法**，*2023.12 – 2024.06*
- 使用 DQN 算法在 OpenAI Gym 环境（Breakout）中训练智能体，达到专家级得分的 98%。
- 采用决策树代理模型对学习到的策略空间进行可解释性分析。
